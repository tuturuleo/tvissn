Автоматическое подключение через Cloudflare-прокси с резервным прямым адресом Render. Вход, обновления и WebSocket переключаются при сетевой ошибке. В popup указан текущий маршрут. ID и сессии сохранены.

Расширение и виджет tvissn — сайт для просмотра больше не используется.

- Компактный виджет без надписи: перетаскивание за ручку, сохранение позиции, локальная громкость и mute.
- Автоскрытие после 2 секунд без движения мыши; меню, клавиатурный фокус, ошибки и перетаскивание удерживают панель.
- Поддержка fullscreen-контейнеров и собственная кнопка fullscreen.
- Опциональный автопереход за общим видео: только подключённая вкладка, запрос доступа для нового домена, отключение после самостоятельной смены адреса.
- Участники комнаты и локальный ping в popup расширения.
- Приглашения создаются и принимаются внутри расширения, без веб-страниц.
- Повторный поиск и выбор плеера сохранены.

ID неизменен. Замените содержимое существующей папки расширения и нажмите Reload на chrome://extensions. Не удаляйте расширение перед обновлением.
