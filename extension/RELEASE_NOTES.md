P2P-версия для двух участников: собственные сервер, signaling, прокси и база не используются. Между расширениями идут только команды и состояние по зашифрованному WebRTC DataChannel.

**Подключение.** Первый создаёт код и отправляет другу, друг принимает его и возвращает ответный код, первый завершает подключение. Коды действуют до 30 минут и относятся к одному подключению; старые приглашения не подходят. Ответный код лучше вернуть быстро. Оба могут ставить паузу, перематывать и менять видео; участники и RTT видны в popup. Соединение хранится в offscreen-документе и не зависит от открытого popup или страницы видео. После перезапуска браузера/расширения или потери связи нужно заново обменяться кодами.

**Обмен через сервер (необязательно).** В «Настройках» можно включить «Обмен кодами через сервер»: MQTT-брокер через WebSocket (по умолчанию `wss://broker.emqx.io:8084/mqtt`) или ntfy. Тогда достаточно передать другу короткий код комнаты — в нём уже есть адрес сервера, ответ придёт автоматически. Сервер видит только хеш-топик и зашифрованные AES-GCM коды. Если сервер недоступен, остаётся ручной код. Свой сервер на Windows поднимает скрипт `tvissn-relay.cmd` из relay-server/windows (ntfy за HTTPS-прокси Caddy; нужны белый IP и проброс TCP 80 и 443).

**Установка на Windows.** Запустите `tvissn-extension-setup.exe` самостоятельно, без прав администратора. Папка по умолчанию: `%LOCALAPPDATA%\tvissn\extension`. Для первой установки включите режим разработчика на chrome://extensions и через Load unpacked выберите точную папку с финального экрана. Если расширение уже подключено из ZIP, выберите в установщике его прежнюю папку с manifest.json, включая нестандартный путь.

**Обновления.** Popup проверяет GitHub API не чаще раза в 30 минут; «Проверить обновления» — сразу. Windows получает EXE, остальные системы и старые релизы без установщика — ZIP. Запустите новый EXE: он обновит файлы в запомненной папке. Для ZIP распакуйте архив в ту же папку с заменой файлов. Затем вручную нажмите Reload на chrome://extensions, не удаляя расширение: так сохраняются ID `fkohpgglbodngaicfehkgdojlbgpbijo` и настройки. EXE не запускается автоматически. Контрольные суммы ZIP и EXE — в latest.json.

Установщик размещает только файлы, не регистрирует расширение в Chrome и не выполняет фоновых обновлений. Chrome на Windows [ограничивает установку вне Chrome Web Store](https://developer.chrome.com/docs/extensions/how-to/distribute); публикация в магазине для полноценной установки и автообновлений — отдельная задача. EXE не подписан.

**Режим отладки.** Включается в «Настройках»: popup показывает диагностику P2P (тип NAT, время сбора кандидатов, время до сбоя ICE, ошибки STUN, состояние сервера обмена) и кнопку её копирования.

**Ограничения.** Используются публичные STUN Google и Cloudflare, TURN нет. При симметричном NAT (часто мобильный или корпоративный интернет) прямое соединение не установится — расширение предупредит об этом и без режима отладки; смените сеть или используйте VPN. P2P раскрывает сетевой адрес собеседнику.
