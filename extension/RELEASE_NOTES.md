Сборка расширения из того же репозитория, что сайт tvissn.

- Chrome/Chromium 116+; синхронизация HTML5-плееров внешних сайтов.
- Вход по коду или ссылке приглашения, подключение текущей вкладки.
- Равное управление, переподключение, выбор iframe, локальная кнопка разрешения воспроизведения.
- Проверка обновлений при открытии popup и кнопка скачивания новой версии.
- Постоянный ID задаётся manifest.key. Для обновления замените содержимое существующей папки и нажмите «Перезагрузить» на chrome://extensions.

ZIP также доступен по адресу вашего сервиса /extension/tvissn-extension.zip. Код репозитория и ZIP не содержат кодов приглашения и токенов участников.
