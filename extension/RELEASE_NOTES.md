P2P-версия для двух участников: собственные сервер, signaling, прокси и база больше не используются.

Создайте код, передайте другу, получите его ответный код и завершите подключение. Старые приглашения не подходят. Пауза, перемотка, новое видео, участники и RTT передаются напрямую через WebRTC. Оба могут управлять. Соединение хранится в offscreen-документе и не зависит от открытого popup или страницы видео.

Используются публичные STUN; TURN отсутствует. Если прямое соединение не устанавливается, смените сеть или используйте VPN. После разрыва/перезапуска расширения нужно заново обменяться кодами.

ID сохранён: замените файлы в прежней папке и нажмите Reload. Chrome может запросить новое разрешение offscreen.

Новые версии — через кнопку GitHub Releases в popup. Серверной проверки обновлений больше нет.
