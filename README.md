# tvissn

Совместный просмотр через Chrome/Chromium-расширение и плавающий виджет на странице видео. YouTube смотрим на youtube.com, другие источники — на их собственных страницах. У сервиса нет HTML-страниц, веб-плеера, веб-входа и служебного сайта.

## Установка

Скачайте ZIP напрямую: https://tvissn.onrender.com/extension/tvissn-extension.zip

1. Распакуйте архив в постоянную папку.
2. На `chrome://extensions` включите режим разработчика и выберите «Загрузить распакованное расширение».
3. Откройте popup tvissn, введите имя и код или вставьте приглашение друга.
4. На странице YouTube или другого сайта с видео нажмите «Смотреть эту страницу вместе».
5. Друзья открывают общую страницу и подключают свою вкладку. Перемотка, пауза и скорость общие; громкость локальная.

ID расширения стабилен: `fkohpgglbodngaicfehkgdojlbgpbijo`. При обновлении заменяйте содержимое **той же папки** и нажимайте «Перезагрузить» в `chrome://extensions`, не удаляя расширение.

## Виджет

- Перетаскивается за ручку, не выходит за границы экрана. Обычный и fullscreen-режимы имеют отдельные сохранённые позиции.
- Во время воспроизведения скрывается после 2 секунд без движения мыши. Движение возвращает его; наведение, меню, перетаскивание, клавиатурный фокус, пауза, ошибка и разрыв связи удерживают панель видимой.
- Громкость и mute меняются только у пользователя и сохраняются между страницами.
- Fullscreen обрабатывается через перенос панели в fullscreen-контейнер и manual popover/top layer. Собственная кнопка разворачивает контейнер плеера, а при выходе восстанавливает изменённые стили. Системный fullscreen и особенности конкретных сайтов требуют отдельной проверки.
- В меню доступны перемотка ±10 секунд, общая скорость, выбор плеера, повторный поиск, установка другого общего видео и отключение.
- В popup расширения отображаются участники, состояния готовности и локальный ping до сервера.

## Автопереход

Отдельно включается в popup или меню виджета и по умолчанию выключен. Расширение может менять адрес **только подключённой вкладки** при смене общего видео, затем повторно обнаруживает плеер и получает текущую позицию комнаты.

Самостоятельная смена адреса выключает режим. Неизвестный домен без доступа не открывается автоматически: popup предлагает «Разрешить и перейти». Редирект на другой сайт или неподходящий итоговый адрес останавливает режим, чтобы не создавать цикл переходов. Формы авторизации и разрешение автозапуска не обходятся.

## Приглашения без сайта

«Пригласить друга» в popup создаёт приглашение на 7 дней вида `tvissn://join?server=...&invite=...`. Его нужно **вставить в поле входа расширения**, а не открывать как веб-страницу. Адрес сервера определяется из приглашения. Поддерживается и старый формат HTTPS-ссылки с `#invite=...` при вставке в расширение.

В приглашении — отдельный подписанный ограниченный по времени код; токен сессии пользователя не передаётся. Обычный первоначальный код также продолжает работать.

## Несколько плееров

Поиск охватывает HTML5 video в странице и доступных iframe. Popup и меню виджета позволяют выбрать конкретный плеер. «Найти плееры заново» очищает старый выбор и повторно обходит страницу. Для iframe другого домена может потребоваться дополнительное разрешение в popup.

Произвольные клики по сайту не синхронизируются. Автовыбор провайдера вроде Kodik и музыка с ведущим — будущие этапы. Закрытый Shadow DOM, нестандартные плееры и реклама могут требовать адаптеров сайта.

## Локальная разработка

Node.js 24 либо 22.12+. Код расширения: `extension/src/`, общие UI-компоненты shadcn: `src/components/ui/`. Сервер: `server/`.

```sh
npm ci
cp .env.example .env
# Укажите INVITE_CODE (8+ символов).
npm run dev:server
npm test
npm run build
```

`npm run build` проверяет TypeScript, собирает CSS для popup, расширение в `extension-dist/`, ZIP и метаданные в `dist/extension/`. **HTML сайта не генерируется.** `popup.html` находится только внутри ZIP расширения.

Без DATABASE_URL локально используется `.data/state.json`. `.env`, `.data/`, `dist/` и `extension-dist/` игнорируются Git. При тестировании своего локального сервера укажите `http://localhost:3000` в popup и разрешите доступ.

## Сервер и AppHub

Проект AppHub `tvissn`, рецепт `docker-postgres`: Docker на Render, PostgreSQL в Supabase, исходники в GitHub. Один процесс синхронизирует одну комнату. Несколько процессов без общего хранилища подключений не поддерживаются.

Публичные маршруты:

- `GET /health`, `/api/health` — JSON health.
- `GET /api/extension/latest` — версия, ID, SHA-256.
- `GET /extension/tvissn-extension.zip` — бинарный ZIP.
- `POST /api/extension/login` — вход расширения.
- `POST /api/extension/invite` — создание приглашения по токену расширения.
- Socket.IO — подписанные сессии расширения.

Остальные маршруты, включая `/`, `/extension`, старые страницы и веб-вход, возвращают 404 JSON. HTTP-ответы имеют Cache-Control: no-store. Сервер принимает команды только с сессией; проверяет версии медиа, дедуплицирует команды и сохраняет контрольные точки. После рестарта восстанавливает видео в паузе. Миграции применяются транзакционно, применённые файлы не изменять. RLS закрывает состояние от публичного Supabase Data API.

Окружение: DATABASE_URL обязателен в production; INVITE_CODE при необходимости заменяет первоначальный verifier; SESSION_SECRET необязателен (без него получается из секрета базы и verifier). Изменение SESSION_SECRET отзывает все сессии. Токены расширения хранятся в доверенном chrome.storage.local и не отправляются в страницу источника. Настройки виджета хранятся отдельно, содержимое страниц и частные ключи в репозиторий не попадают.

Бесплатный Render может просыпаться около минуты после простоя. PostgreSQL нужно резервировать штатными pg_dump/pg_restore; секреты хранить отдельно от исходников.

## Автоматические релизы

`.github/workflows/extension-release.yml` запускается при изменениях расширения и его зависимостей. Он генерирует возрастающую четырёхкомпонентную Chrome-версию, проверяет тесты и сборку, коммитит `extension/release.json`, публикует GitHub Release с ZIP и latest.json. Bot-коммит запускает Render, где собирается тот же ZIP.

Popup проверяет обновления при открытии и по кнопке. Новая версия показывается с кнопкой скачивания; ссылка содержит номер версии для обхода старого кэша. Chrome не устанавливает произвольный ZIP автоматически — замените файлы в существующей папке и нажмите Reload. `extension/identity.json` не менять: его публичный ключ фиксирует ID между релизами. Не переписывайте автоматический release.json старой локальной копией.
