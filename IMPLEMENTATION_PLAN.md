# tvissn: P2P вместо серверного режима

Реализовано: два участника, ручной offer/answer с истечением срока и привязкой к UUID подключения, зашифрованный RTCDataChannel, STUN без TURN, offscreen WEB_RTC, локальный координатор команд с равными правами управления, ACK и дедупликация, таймеры и RTT, закрытие при потере связи, прежний виджет/плееры/автопереход.

Необязательный релей кодов (extension/src/relay.ts): MQTT-брокер через WebSocket (`wss://`, по умолчанию `wss://broker.emqx.io:8084/mqtt`, retained-сообщения) или ntfy (`https://`, история топика). Топик `tvissn_…` — хеш SHA-256 от секрета комнаты, коды шифруются AES-GCM; секрет и адрес сервера есть только в коде комнаты. При недоступности сервера остаётся ручной обмен.

Режим отладки и диагностика NAT (extension/src/offscreen.ts): тип NAT, время сбора кандидатов, время до сбоя ICE, ошибки STUN, состояние сервера обмена; симметричный NAT определяется по разным портам от двух STUN-серверов, и предупреждение показывается без режима отладки.

Проверка обновлений (checkUpdate/downloadUpdate в extension/src/background.ts): последний выпуск через GitHub API, кеш на 30 минут, принудительная проверка кнопкой, скачивание ZIP через chrome.downloads. Установка обновления — распаковка в ту же папку и Reload, ID стабилен.

Свой сервер обмена (relay-server/windows): `tvissn-relay.cmd` ставит ntfy за HTTPS-прокси Caddy как службы Windows `tvissn-ntfy` и `tvissn-caddy`, адрес через nip.io/sslip.io, DuckDNS или свой домен; по умолчанию обслуживает только топики `tvissn_*`.

Код серверного режима, базы, Docker и Cloudflare-прокси удалён. Выпуск ZIP остаётся в GitHub Actions. Приватный репозиторий требует доступа для скачивания релизов. Работа на реальных NAT требует проверки двух участников.

Инфраструктура: отключить Cloudflare Worker tvissn-proxy; остановить/удалить Render tvissn через панель провайдера/AppHub (в MCP такой команды нет). Базы можно удалить отдельно после решения о сохранности старых данных; приложение их не использует.

На будущее: группы более двух человек, повторное автоматическое ICE-соединение, выбранный пользователем TURN, режим музыки/ведущего, выбор источников на сайтах. Эти функции в текущий выпуск не входят.
