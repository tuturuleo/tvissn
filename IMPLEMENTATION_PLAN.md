# tvissn — текущий объём и следующие этапы

Обновлено 29 октября 2026 года.

## Текущий релиз

- Приложение состоит из Chrome/Chromium-расширения, виджета на странице видео и сервера API. HTML-страниц сервиса нет, включая служебные.
- Одна общая комната. Вход по коду/приглашению внутри расширения. Приглашения также создаются в расширении.
- Все участники равноправно управляют видео. Чата, звонков и очереди нет.
- YouTube и другие сайты воспроизводятся у каждого на исходном сайте. HTML5-плееры обнаруживаются в странице и доступных iframe; доступ к новым доменам выдаётся явно.
- Мини-виджет: ручка перетаскивания без надписи, play/pause, ручная синхронизация, локальная громкость/mute, fullscreen, сворачивание и меню.
- Положение хранится локально; отдельно для обычного и fullscreen-режима. Перетаскивание ограничено экраном.
- Во время воспроизведения панель затухает за 300 мс после 2 секунд без движения мыши. При наведении, клавиатурном фокусе, открытом меню, перетаскивании, паузе и ошибке она остаётся видимой.
- Меню: выбор и повторный поиск плеера, перемотка, скорость, другое видео, отключение и опциональный автопереход.
- Popup расширения: вход, приглашения, участники с состояниями, локальный ping до сервера, подключение вкладки, разрешения iframe и обновления.
- Автопереход по умолчанию выключен и действует только на выбранную вкладку. Смена общего видео приводит к переходу и повторному поиску плеера. Самостоятельная смена адреса выключает режим. Для нового домена без доступа нужен пользовательский запрос в popup; редиректы останавливают автоматическую навигацию.
- Сервер: TypeScript/Fastify + Socket.IO, PostgreSQL, одна последовательность команд и контрольные точки состояния. После рестарта — пауза на последней сохранённой позиции.
- Размещение: AppHub, Render Docker + PostgreSQL Supabase, тот же GitHub-репозиторий.
- Релизы расширения автоматические через GitHub Actions. ID закреплён публичным ключом; ZIP и latest.json доступны напрямую с API-сервиса. Распакованная установка обновляется заменой файлов в той же папке и Reload.

## Проверка

Автотесты: протокол, повторные команды, сессии и отдельные приглашения, API без HTML, внешнее видео, несколько плееров и повторный поиск, локальная громкость, drag, автоскрытие, fullscreen, участники/ping в popup, opt-in автопереход, разрешения и гонки двух смен источника.

Браузерная проверка на собственном тестовом видео: внешний вид, перетаскивание, громкость, скрытие/появление панели и видимость в fullscreen. Совместимость конкретных сторонних плееров проверяется отдельно; универсальность для любого сайта не гарантируется.

## Будущие этапы — не входят в текущий релиз

1. Синхронизация выбора провайдера (Kodik и т.п.): адаптеры популярных сайтов либо ограниченный opt-in режим повтора клика по переключателю. Проверять selector/iframe/роль/текст; при неоднозначности просить подтверждение. Не передавать произвольные клики по всей странице и действия в формах.
2. Музыка (например, Яндекс Музыка): выбравший источник управляет переключением треков и очередью; перематывать могут оба, громкость локальная. Политику play/pause уточнить при реализации.
3. YouTube-плейлисты с такой же моделью ведущего для смены роликов. Аудиорежим оценивать по реальной нагрузке: скрытие картинки само по себе не гарантирует отключение декодирования и загрузки видеопотока.
